# Добавить списком — массовое добавление маршрутов в Keenetic

Кнопка **«Добавить списком»** в разделе «Маршрутизация» веб-интерфейса роутеров Keenetic.
Вставляете домены, IP-адреса или HAR-файл из браузера, выбираете маску и интерфейс — маршруты
добавляются сразу. Без генераторов `.bat`-файлов, без консоли и без перепрошивки.

**[⬇ Скачать hostsgen-ui.tar.gz](https://github.com/PavelDemyanov/keenetic-hostsgen-ui/releases/latest/download/hostsgen-ui.tar.gz)** — последняя версия, все выпуски — в разделе [Releases](https://github.com/PavelDemyanov/keenetic-hostsgen-ui/releases).

## Что умеет

- Принимает домены, IP-адреса, подсети (`1.2.3.0/24`), ссылки и строки `route ADD … MASK …` —
  по одному в строке, через пробел или запятую.
- Перетащите в окно HAR-файл из инструментов разработчика браузера — модуль достанет из него все домены
  и адреса серверов, к которым подключался сайт. Лишние домены можно удалить из списка.
- Домены распознаёт DNS самого роутера — те же адреса, что получат устройства вашей сети.
- Маска подсети: /32 (только адрес), /24, /16 или /8. Интерфейс (VPN, провайдер) и политика доступа —
  из списков роутера; по умолчанию — интерфейс, через который у вас больше всего маршрутов.
- Перед добавлением показывает, какие маршруты новые, а какие уже покрыты существующими.
- Нет ограничения штатного импорта в 1024 строки.
- Работает и в локальной сети, и при удалённом входе через KeenDNS.

## Установка — только через веб-интерфейс

**Нужно:** роутер Keenetic с KeeneticOS 5, файл `hostsgen-ui.tar.gz` и — если у роутера нет встроенного
хранилища для пакетов — флешка, которую можно стереть.

### 1. Включите поддержку пакетов

«Управление» → «Настройки системы» → «Изменить набор компонентов» → в группе «Пакеты OPKG» отметьте
**«Поддержка открытых пакетов»** и установите обновление. Роутер скачает обновление и перезагрузится —
на 5–10 минут пропадёт интернет.

### 2. Выберите, куда ставить

Откройте «Управление» → «OPKG» и раскройте список «Накопитель».

- **Есть пункт «Встроенное хранилище»** — ставьте туда, флешка не нужна. Переходите к шагу 3.
- **Нет такого пункта** — вставьте флешку в USB-порт роутера, откройте «Управление» → «Накопители и
  устройства», у флешки нажмите **«Форматировать»**, выберите файловую систему **EXT4** и подтвердите.
  Всё, что было на флешке, удалится.

### 3. Загрузите архив на накопитель

«Управление» → «Накопители и устройства» → нажмите на накопитель (встроенное хранилище или флешку) —
откроется окно «Файлы и папки».

1. Нажмите «Создать папку» и назовите её `install`.
2. Выделите папку `install`, нажмите «Загрузить файл» и выберите `hostsgen-ui.tar.gz`.

### 4. Подключите накопитель

«Управление» → «OPKG» → «Накопитель»: выберите тот же накопитель → **«Сохранить»**.

Роутер сам распакует архив (папка `install` опустеет) и встроит кнопку — это занимает пару секунд.
Если накопитель там уже был выбран, роутер не заметит новый архив: сначала выберите «Не выбран» →
«Сохранить», затем снова нужный накопитель → «Сохранить».

### 5. Проверьте

Откройте «Сетевые правила» → «Маршрутизация» и обновите страницу (F5, на Mac — Cmd+R). Рядом с кнопкой
«Добавить» появится **«Добавить списком»**. Если кнопки нет — загляните в «Управление» → «Диагностика» →
журнал: строки с `hostsgen-ui` подскажут, что пошло не так.

## Как пользоваться

1. «Маршрутизация» → «IPv4-маршруты» → **«Добавить списком»**.
2. Вставьте список адресов или перетащите HAR-файл.
3. Выберите маску, интерфейс и, если нужно, политику и описание → «Показать маршруты».
4. Проверьте таблицу и нажмите «Добавить N маршрутов». Таблица маршрутов обновится сама.

**Как получить HAR-файл.** Откройте сайт в браузере, нажмите F12 (на Mac — Cmd+Option+I), перейдите на
вкладку «Сеть» (Network), обновите страницу и походите по сайту, затем нажмите на значок загрузки
«Export HAR» (или правый клик по списку запросов → «Save all as HAR»). HAR разбирается прямо в браузере
и никуда не отправляется.

## Обновление

Загрузите новый `hostsgen-ui.tar.gz` в папку `install` (шаг 3) и переподключите накопитель:
«OPKG» → «Накопитель»: «Не выбран» → «Сохранить» → снова накопитель → «Сохранить».

## Отключение и удаление

- **Отключить:** «OPKG» → «Накопитель»: «Не выбран» → «Сохранить». Интерфейс сразу станет обычным;
  включить обратно — выбрать накопитель снова.
- **Удалить совсем:** отключите, затем в «Файлы и папки» удалите на накопителе папку `share/hostsgen-ui`
  и файлы `etc/init.d/S99hostsgen-ui` и `etc/initrc`.

Если на накопителе уже стоит Entware, всё работает так же: модуль ставится рядом и запускается вместе с ним.

## Совместимость

- KeeneticOS 5 с новым веб-интерфейсом. Проверено на Keenetic Giga (KN-1011), KeeneticOS 5.2.
- В архиве сборки под все процессоры Keenetic: MIPS little-endian (MT7621 — Giga KN-1010/1011 и другие),
  MIPS big-endian (DSL-модели на EcoNet) и ARM64 (MT7981/MT7622/MT7988 — новые модели). Нужная выбирается
  автоматически. На железе пока проверена только MIPS (MT7621) — если у вас другая модель, расскажите в
  [Issues](https://github.com/PavelDemyanov/keenetic-hostsgen-ui/issues), заработало ли.
- Флешка — в EXT4: другие файловые системы для пакетов не проверялись.
- Только IPv4-маршруты.

## Как это работает и безопасно ли это

Прошивка не меняется. Архив ставится штатным механизмом OPKG: при подключении накопителя роутер
распаковывает его и запускает модуль. Модуль кладёт в оперативную память роутера копию стартовой
страницы веб-интерфейса со встроенным скриптом кнопки и подменяет ею оригинал (`mount --bind`).
При отключении накопителя или перезагрузке без него интерфейс снова родной; после обновления прошивки
модуль сам встраивается в новую версию страницы.

Модуль не открывает портов, не ставит серверов и ничего не отправляет наружу. Маршруты добавляются
теми же командами API роутера, что и штатная кнопка «Добавить», — под вашим входом в веб-интерфейс.
Домены распознаёт небольшая программа на роутере через его собственный DNS.

## Для разработчиков

```
web/addon.js            модуль страницы: диалог, разбор ввода и HAR, подсети, вызовы API роутера
helper/hostsgen-ui.c    статическая программа: встраивание в интерфейс (start/stop) и DNS (resolve)
router/S99hostsgen-ui   init-скрипт: выбирает сборку под процессор по заголовку ELF /bin/sh
router/initrc           сценарий запуска OPKG для накопителя без Entware
tools/pack.py           упаковка архива в формате GNU tar (иначе распаковщик прошивки его не примет)
tests/                  тесты addon.js (node --test)
```

```bash
./build.sh                      # тесты + сборка под три процессора + dist/install/hostsgen-ui.tar.gz
ROUTER=root@192.168.1.1 ./deploy.sh   # выложить на роутер с Entware по SSH (порт 222)
```

Для сборки нужны Node.js, Python 3 и [Zig](https://ziglang.org) (кросс-компиляция C со статическим musl).
Подробности устройства и известные подводные камни — в [CLAUDE.md](CLAUDE.md).
